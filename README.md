# Рабочий календарь — PWA

Адаптивное приложение-календарь с графиком 2/2, выплатами 10-го и 25-го, загрузочным экраном, анимациями, тёмной/светлой темой и сохранением настроек на устройстве.

## Запуск локально

PWA и Service Worker работают на `localhost` или HTTPS. В папке проекта запустите локальный сервер:

```bash
python -m http.server 8080
```

Откройте http://localhost:8080

## Установка на телефон/ПК

Разместите файлы на HTTPS-хостинге (например, GitHub Pages, Netlify или собственный хостинг). Откройте сайт в поддерживаемом браузере и выберите «Установить приложение» / «Добавить на главный экран». После первого открытия основные файлы кешируются и приложение может открываться без сети.

## Настройки по умолчанию

- График: 2 рабочих дня / 2 выходных.
- Первый рабочий день цикла: текущая дата при первом запуске (по умолчанию сегодня и завтра рабочие).
- Зарплата: 8 300 ₽ в месяц, поровну между двумя выплатами (4 150 ₽ на каждую).
- 10-го: вторая половина прошлого месяца.
- 25-го: первая половина текущего месяца.

Зарплату и дату начала цикла можно изменить в интерфейсе. Данные хранятся в localStorage этого браузера/устройства.
