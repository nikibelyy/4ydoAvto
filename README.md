# Рабочий календарь — PWA

Минималистичное приложение на React + Vite с графиком 2/2, расчётом плановых выплат, статистикой, тёмной темой и Service Worker.

## Требования

- Node.js 20 LTS или новее
- npm
- Для установки на телефон в production — HTTPS. На `localhost` PWA работает для разработки.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

## Production-сборка

```bash
npm run build
npm run preview
```

Содержимое каталога `dist/` можно развернуть на любом статическом хостинге с HTTPS (например, Netlify, Vercel или GitHub Pages с настройкой base path).

## PWA: manifest, Service Worker и иконки

- `public/manifest.json` описывает имя приложения, режим standalone, цвета и иконки.
- `public/sw.js` кеширует app shell и ресурсы same-origin, чтобы приложение могло открываться офлайн после первого успешного посещения.
- Регистрация Service Worker выполняется в `src/main.jsx` только для production-сборки.
- Добавьте PNG-иконки `public/icons/icon-192.png` и `public/icons/icon-512.png`. Подойдут квадратные PNG с логотипом календаря. Для iOS дополнительно рекомендуется добавить `<link rel="apple-touch-icon" href="/icons/icon-192.png">` в `index.html`.
- Браузер показывает установку через `beforeinstallprompt` не на всех платформах. На iOS используйте «Поделиться» → «На экран Домой».

Если используете подкаталог сайта, обновите `base`, `start_url`, `scope` и пути к ресурсам соответственно.

## Правила графика и зарплаты

- Цикл: 2 рабочих дня, затем 2 выходных.
- В настройках указывается дата первого рабочего дня цикла.
- Ставка: 8 300 ₽ за рабочий день.
- Выплата 10-го числа рассчитывается за рабочие дни с 16-го по последний день предыдущего месяца.
- Выплата 25-го числа рассчитывается за рабочие дни с 1-го по 15-е число текущего месяца.
- Суммы являются плановыми и не включают налоги, премии, больничные или фактические корректировки.
- Настройки сохраняются локально в `localStorage`; аккаунт и сервер не требуются.

## Примечания

Первый экран-заставка появляется при каждой загрузке страницы. После первого онлайн-запуска Service Worker сохраняет app shell и кеширует посещённые ресурсы. Для гарантированного офлайн-кеша всего production bundle можно расширить precache-список автоматически генерируемыми файлами сборки (например, через `vite-plugin-pwa`).

## Публикация на GitHub Pages

1. Создайте публичный репозиторий с названием `rabochiy-calendar`.
2. Загрузите в корень репозитория все файлы проекта, включая скрытую папку `.github`.
3. Откройте **Settings → Pages** и в разделе **Build and deployment** выберите **GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь завершения workflow `Deploy PWA to GitHub Pages`.
5. Сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/rabochiy-calendar/`.

Workflow уже задаёт base path для репозитория `rabochiy-calendar`. Если назовёте репозиторий иначе, поменяйте `base` в `vite.config.js` на `/${ИМЯ-РЕПОЗИТОРИЯ}/`.

## Дополнительные модули

- `src/utils/date.js` — даты и форматирование.
- `src/utils/schedule.js` — вычисление графика 2/2 и количество смен.
- `src/utils/finance.js` — расчёты зарплаты, периодов выплат и месячной статистики.
- `src/components/ErrorBoundary.jsx` — экран восстановления при ошибке React.
- `src/components/OfflineStatus.jsx` — индикатор потери соединения.
- `src/components/InstallHelp.jsx` — подсказка по установке на смартфон.
- `src/utils/schedule.test.js` — автоматические тесты расчёта смен и выплат.

Запуск тестов: `npm test`.
