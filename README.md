# Мой рабочий календарь — PWA

## Возможности
- Только тёмная тема, переключателя темы нет.
- Календарь и повторяющийся график 2/2.
- Ставка по умолчанию: 8 300 ₽ за рабочий день.
- Настраиваемое число рабочих дней за месяц (по умолчанию 15).
- Карточка ближайшей выплаты на главной с датой, обратным отсчётом, прогрессом и настраиваемой суммой (по умолчанию 25-е число и 66 400 ₽).
- Чёткие векторные SVG-иконки в шапке и нижней навигации.
- Расчёт: ставка × рабочие дни + доплаты выбранного месяца.
- Добавление и удаление премий, бонусов и других доплат.
- Анимированная заставка, адаптация под телефоны, установка на главный экран.
- Локальное сохранение настроек и доплат.
- Service Worker для кеширования приложения и офлайн-открытия.

## Расчёт
15 рабочих дней × 8 300 ₽ = 124 500 ₽ базовой зарплаты. Доплаты прибавляются сверху. Если на 25-е число у тебя выплата 66 400 ₽, она, вероятно, является частью зарплаты/авансом за период, а не полной зарплатой за 15 дней. В приложении месячный заработок рассчитывается отдельно; фактическое распределение по датам выплат зависит от правил работодателя.

## Запуск
PWA требует HTTPS или localhost. Локально:
```bash
python -m http.server 8080
```
Открой http://localhost:8080. Для установки на телефон размести файлы на HTTPS-хостинге и выбери «Установить приложение» / «Добавить на главный экран».
